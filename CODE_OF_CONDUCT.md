# Code of Conduct

We want InitiumDb to be a welcoming project for everyone, regardless of
experience, background or identity.

## Our standards

- Be respectful and constructive; assume good intent.
- Welcome newcomers and give feedback on the work, not the person.
- Accept that maintainers decide what fits the project's scope.

Unacceptable behavior includes harassment, discrimination, personal attacks,
trolling, publishing other people's private information, and any conduct that
would be inappropriate in a professional setting.

## Scope

This applies to all project spaces (issues, pull requests, discussions) and to
public representation of the project.

## Enforcement

Maintainers may edit or remove comments, and may temporarily or permanently
ban contributors for behavior that violates this code. Report problems to
**contacto@etimo.cl**; reports are handled confidentially.

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
