# Current state

- Project bootstrapped: governance, test prompts, Maven project (Java 25, `cl.etimo.initiumdb`).
- Implemented: `idb-init`, `idb-crypt` (DEC-003), `idb-capture` and `idb-prepare` (DBUnit `REFRESH`, declared table order) in `cli`, with `core` services, configuration loaders, `ConnectionResolver`/`CredentialProvider` and `DbUnitSession`.
- A case is a directory (`--case`) holding a fixed-name `case.yml` (`version`, ordered `databases: [{alias}]`); per alias the files are fixed by convention: `<ALIAS>.queries.yml`, `<ALIAS>.dataset.xml`, optional `<ALIAS>.pre.sql`/`<ALIAS>.post.sql` (absent or empty run nothing) (DEC-009). SQL hooks support per-statement guards `-- idb:run-if <query>` / `-- idb:skip-if <query>` (DEC-010); other comments are kept as written. In `queries.yml`, `tables[].sql` is optional and defaults to `SELECT * FROM "<name>"` (name quoted, DEC-005).
- `idb-init --alias [ENGINE:]NAME` (repeatable, required, upper-cased) is cumulative and never overwrites: it creates or extends `case.yml`, environment and secrets files, adding only missing databases, and creates any missing `<NAME>.queries.yml` and empty hook files (YAML/JSON read and written with Jackson, never as text, so comments of rewritten YAML files are not kept; no `--overwrite`).
- Aliases and credential names: upper case, digits, `_` (`core/Names`), validated in case, environment, secrets files and `idb-init`; `credential` optional (default alias); `IDB_<ALIAS>_ENGINE/URL/USER` override or replace the environment file.
- Engines: `oracle` and `postgresql` as thin profiles (DEC-004); object names exact, SQL by engine rules (DEC-005).
- `idb-capture` rejects table or column names that are not valid XML names (PEND-006 tracks encoding them).
- Tooling: Maven, JUnit 5, AssertJ, Mockito 5.20.0 with byte-buddy 1.17.7 (needed on Java 25), Testcontainers 2.0.2, Spotless (google-java-format 1.28.0), `-Xlint:all -Werror`, pre-commit.
- Verified on JDK 25.0.2 (`C:\Util\Java\jdk-25.0.2`; the default `JAVA_HOME` is JDK 1.7, so set it explicitly): `mvn verify` (59 unit tests, 3 `DistributionIT`) and `mvn spotless:check` pass.
- JDBC drivers are user-supplied (`drivers/` folder, DEC-008).
- Packaging: `mvn package` builds the folder distribution and archives (DEC-008); `DistributionIT` (Failsafe, in `mvn verify`) runs the launchers; the shell launchers were checked on Git Bash only, not on a real Unix.
- Oracle and PostgreSQL apply the dataset with batched upserts (`BatchedUpsertOperation`, DEC-011): `MERGE` on Oracle, `INSERT ... ON CONFLICT` on PostgreSQL. Both are checked against real containers (opt-in profiles) and Oracle also on H2; timing on the user's Oracle case: 520 s with `REFRESH` vs 10 s.
- Opt-in integration tests against disposable containers (Docker required): `-Ppostgresql-integration` and `-Poracle-integration`, 2 tests each, both pass (Oracle: 3 tests in about 150 s on a laptop, the image needs about 2 minutes to open its database, so the test allows 6 minutes).
- Licensing and governance follow DEC-012: Apache 2.0 `LICENSE`, `NOTICE`, dual-licensing and commercial-edition notices, `THIRD_PARTY_LICENSES.md`, `CONTRIBUTING.md`, `DEVELOPMENT.md`, `.github/CODEOWNERS`, CI in `.github/workflows/ci.yml` (not yet run on GitHub), release in `release.yml`.
